Prepare a compact handoff for a completely fresh AI session.

1. Resolve the mode: reusable agent/case, project, or research.
2. Update the owning state file with:
   - current objective
   - work completed
   - current behavior and verified results
   - blockers or uncertainties
   - files currently involved
   - exact next action
3. Update the owning task file.
4. Record durable technical choices in the owning decisions file.
5. Add a detailed dated session note when useful.
6. For a reusable agent, record the selected case, stage verdicts, redacted
   evidence paths, endpoint roles, required approvals, and blocked/unverified
   stages. Never copy `.env`, credentials, raw inputs, exports, or records.
7. If application files changed, prepare a separate handoff in the owning
   project repository.
8. Keep state concise; link to detailed documents instead of copying them.
9. Do not claim a check passed unless it was actually run.
