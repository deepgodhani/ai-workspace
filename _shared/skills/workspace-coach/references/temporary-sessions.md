# Temporary Sessions

Use `temp-sessions/<name>/` for disposable cross-workspace analysis when no
permanent repository should own the output yet. Name external read-only context
explicitly. Write every generated file inside the current temporary-session
folder and do not modify the consulted repositories.

Promote a result later only after choosing one owning agent/case, project,
research topic, or knowledge repository. Delete or archive temporary material
deliberately; never treat it as canonical by accident.
