# Knowledge

Durable, verified, model-independent notes in Markdown. Only conclusions that
survived research or real use belong here; raw crawls stay in
`research/topics/*/raw/`.

- `inbox/` — unverified candidates (written by `$workspace-coach`)
- `daily/YYYY/MM/YYYY-MM-DD.md` — daily summaries (written by `$daily-summary`)
- `indexes/` — entry points; register work held outside the workspace in
  `indexes/external-targets.md`

Split into subject spaces (each with its own `concepts/`, `technologies/`,
`indexes/`) once a subject grows large enough to dilute others.

This folder is git-ignored in the framework repo; keep it as its own repo if
you want history.
